# 16_02: 卷积 QoI — 偏置协调算式推导与多维度推广

## 1. 问题形式化

**符号约定**：核 `K[w] = [k₀, k₁, ..., k_{w-1}]`，左对齐卷积（convention）：
```
c[p] = Σ_{j=0}^{w-1} k_j · x[p + j]    (0 ≤ p ≤ N-w)
```
即卷积输出落在 `[0, N-w]`，与核左端对齐。居中核可通过改换 `p` 的偏移等价表示，不丢失信息。

解码值与原始值的偏差：
```
e[i] = x_dec[i] - x_orig[i]
```
实际 e[i] 无法精确控制（量化误差取决于 eb 和预测器），但可以通过 **偏置 β[i]** 主动偏移目标值：
```
x_dec[i] ≈ x_orig[i] + β[i] + ε[i]    （ε 为量化残差，|ε| ≤ eb）
```

**约束**：对每个卷积输出 `p`，要求：
```
|c_dec[p] - c_orig[p]| ≤ tol
```

代入展开：
```
c_dec[p] - c_orig[p] = Σ k_j · β[p+j] + Σ k_j · ε[p+j]
```

暂时忽略 ε（假设 eb 足够小使得 `Σ k_j · ε` 可被 tol 吸收），约束退化为：
```
| Σ k_j · β[p+j] | ≤ tol    ∀ p ∈ [0, N-w]
```

这就是核心约束系统：**N 个 β 变量、N-w+1 个双边不等式**。

---

## 2. 窗口耦合结构

## 2.1 核大小与耦合半径

设 w=3，K=[a,b,c]（注意：这里的 b 是中心权重，在左对齐约定下 x[p+1] 参与 c[p] 的权重是 b）。

```
c[0] = a·x[0] + b·x[1] + c·x[2]
c[1] =               a·x[1] + b·x[2] + c·x[3]
c[2] =                         a·x[2] + b·x[3] + c·x[4]
```

每个 β[i] 出现在 **至多 w 个约束**中：
- `β[i]` 参与 `c[i-w+1]`、`c[i-w+2]`、…、`c[i]`
- 对应的权重分别是 `k_{w-1}`、`k_{w-2}`、…、`k_0`（从最左参与窗口到最右参与窗口）

约束矩阵 `A[(N-w+1) × N]` 是一个 **带状（banded）矩阵**，带宽 = w。

### 2.2 约束冲突何时发生

单窗口约束是松弛的（tol 给了一带宽容忍），所以冲突只发生在：**连续 w 个窗口都朝同一方向偏时，累积的约束把中间的 β 锁死**。

例如 w=3, K=[1,1,1]（简单滑动平均）：
```
c[0] = β[0] + β[1] + β[2]   ∈ [-tol, tol]
c[1] = β[1] + β[2] + β[3]   ∈ [-tol, tol]
c[2] = β[2] + β[3] + β[4]   ∈ [-tol, tol]
```

如果 c[0] 和 c[2] 都已经被推到了 `+tol` 边界，c[1] 的空间就只剩 `[-tol, tol] - 在途 = -tol` 到 `tol - 在途`，可能无解。

**这就是"误差累积"的数学本质**——不是指数增长，而是约束系统在狭窄带内相互"挤"。

## 3. 两遍全局求解（Two-pass Global Solution）

### 3.1 问题转化为最小二乘

优化目标：最小化偏置平方和，同时满足所有窗口约束。

```
minimize   Σ_{i=0}^{N-1} β[i]²
subject to | Σ_{j=0}^{w-1} k_j · β[p+j] | ≤ tol    ∀ p
```

等价于解一个 **bounded-variable 带状线性系统**。不需要通用 LP 求解器，可以用 **投影梯度法**（projected gradient）迭代，收敛快：

**投影梯度迭代**：
1. 所有 β[i] ← 0
2. 对每个窗口 p ∈ [0, N-w]：
   - `δ[p] = Σ k_j · β[p+j]`（当前偏差，含之前迭代的更新）
   - 若 `|δ[p]| > tol`：
     ```
     excess = δ[p] - sign(δ[p]) · tol
     // 将 excess 分配回窗口内的 β，按权重比例
     for j in 0..w-1:
         β[p+j] -= excess · k_j / (Σ k_j²)  ​// 权重归一化分配
     ```
3. 重复直至所有窗口合规，或 max_iter（通常 3-5 次足够，因为带状约束的全局结构是局部化的）

与神经网络中的 "projected gradient for linear constraints" 等价。

### 3.2 复杂度

每轮扫一遍窗口数 N-w+1，每窗口 O(w)，总 O(w·N)。3-5 轮后收敛，整体 O(w·N) ≈ O(N)（w 很小）。

---

## 4. 滑动窗口流式求解（Streaming Solution via Block）

两遍求解虽然精确，但需要全局数据。如果只允许在一个 block 内操作（`precompress_block`），可用 **带重叠区的块切分**：

### 4.1 块内求解 + 块间重叠

将 [0,N-1] 切成 blocks，每个 block 前后各 pad w-1 个点（与相邻块重叠）：

```
block k 的工作范围：[k·B, (k+1)·B + w-1]
独享范围：        [k·B + w-1, (k+1)·B]
```

解释：
- 块边界延长覆盖了跨块卷积窗口，保证约束在块内闭合
- **独享范围**是只有本块才能决定 β 的范围（左右各 w-1 个重叠点属于上下块）
- 在每个 block 内运行投影梯度（仅对独享范围求解，重叠区继承上块的结果）

边界效应：第一个块左 w-1 个点、最后一个块右 w-1 个点没有完整卷积窗口 → 无约束，β=0, eb=geb。

### 4.2 块大小选择

- B 越大：投影梯度迭代的 N 越大，但块边界浪费占比越小
- B 越小：更像实时流式，但重叠开销和边界浪费变大
- 推荐 B = 64~256（覆盖典型 SZ3 block size），w=3~5 时重叠占比 3%~8%

---

## 5. 全局滑动 vs 块内滑动：对比

| | 全局滑动（两遍） | 块内滑动（precompress_block） |
|---|---|---|
| 数据范围 | 整个数组 | 每个 block（含重叠） |
| 块边界影响 | 无（连续求解） | 边界点 β=0，浪费部分预算 |
| 压缩器修改 | 需 dispatcher 层一次调用 `precompute` | 不改 dispatcher，仅 `precompress_block` 内部实现 |
| 内存 | 全局存 β 数组 | 每 block 临时存 β 数组（B+w） |
| 并行性 | 逐点串行（带状耦合） | 块间可并行 |
| 编码/解码依赖 | 需在码流中带上 β？ | β 只在 compress 侧用，不进入码流 |

### 推荐

**先用块内滑动验证可行性**（改动最小），如果精度不够再升级到全局。两者的算式核心（投影梯度）完全一样，唯一区别是求解的数据范围。

## 6. 2D 推广

### 6.1 2D 卷积 QoI 定义

2D 核 `K[wx × wy]`，在 `(p,q)` 处的卷积：
```
c[p,q] = Σ_{i=0}^{wx-1} Σ_{j=0}^{wy-1} K[i,j] · x[p+i, q+j]
```

约束同 1D：`|c_dec[p,q] - c_orig[p,q]| ≤ tol`。

### 6.2 约束耦合结构（2D 带状）

每个 `β[i,j]` 出现在 `wx × wy` 个卷积窗口中，形成 **2D 带状约束**。1D 是 tri-diagonal（w=3 时每 β 参与 3 个约束），2D 是 **wx·wy 个约束 + wx·wy 个邻居耦合**。

投影梯度推广到 2D：
```
for each valid window (p,q):
    δ[p,q] = Σ_{i,j} K[i,j] · β[p+i, q+j]
    if |δ| > tol:
        excess = δ - sign(δ)·tol
        for i in 0..wx-1, for j in 0..wy-1:
            β[p+i,q+j] -= excess · K[i,j] / (Σ K²)
```

复杂度 O(wx·wy·N_rows·N_cols)，对常见的 3×3 kernel 仍然 O(N)。

### 6.3 2D 块切分

```
block (r,c): 工作范围 = [r·B_rows, (r+1)·B_rows + wy-1]
                        × [c·B_cols, (c+1)·B_cols + wy-1]
独享范围:     [r·B_rows + wy-1, (r+1)·B_rows]
            × [c·B_cols + wy-1, (c+1)·B_cols]
```

与 1D 完全一致的逻辑——各方向 pad (kernel_size - 1)，边界无约束。

### 6.4 2D 与现有 SZ3 架构的匹配

SZ3 的 `precompress_block` 传入 N=num_elements（纵向展开），不直接暴露 2D 行列结构。但 `Config` 中有 `dims` 向量，可从中重构 2D 布局。QoI_Conv 需要：
1. 从 `conf.dims` 提取 rows × cols
2. 在 `precompute` 中将 1D 索引映射回 2D 坐标
3. 运行 2D 投影梯度
4. `get_bias(1D_idx)` 直接取预计算的 β 值

## 7. 投影梯度为什么收敛（简易证明）

每一步 projection：对违规窗口 p，将 `δ[p]` 投影回 `[-tol, tol]` 区间，按权重的平方比例分配修正量给 β。因为带状约束满足 **有限部分重叠**（每对窗口最多共享 w-1 个变量），修正传播是**受限**的——局部违规只影响局部，不会产生全局连锁。

类比：高斯-赛德尔迭代解线性方程组 Ax=b，A 是带状正定矩阵时，O(w·N) 步收敛到指定精度。投影变体（含不等式约束）收敛性同。

在实际卷积 QoI 中，tol 足够大时（通常不是接近 0），5 次迭代已足够让所有窗口合规。

## 8. 简化方案：滑动窗口偏置的实用化

如果不想解 LP（即使是简化的投影梯度），也有一个更"土"但有效的方案：

**开窗平均纠偏**：每个点 x[i] 参与 w 个窗口。对每个窗口 p 计算"理想偏置"：

```
ideal_bias[i] = - Σ_{p: p ≤ i < p+w} K[i-p] · acc_err[p] · k_weight
                                              / (Σ over windows of K²)
```

即：x[i] 把自己的"影响力"按权重比例，反向分配到它参与的所有窗口的累积误差上。

形式上等价于投影梯度的一次迭代（用累积误差去纠正），工程上已足够。
