# Regional 编码重新设计 — 实现计划

## 动机

将 Regional QoI 的编码从简单 `~rid` 升级为 nibble 编码 + Block/Interp/FX flag，支持任意函数表达。与 pointwise nibble 编码完全对称。

## 实现步骤

### Step 1: RegionalEncoding 工具

```cpp
// 翻转前语义结构
struct RegionalRaw {
    bool is_interp;   // bit30
    bool use_fx;      // bit29-28 == 3
    int  nibble_qoi;  // bit27-0
};

inline RegionalRaw decode_regional(int qoi) {
    int raw = ~qoi;
    return {(bool)((raw>>30)&1), ((raw>>28)&0x3)==3, raw & 0x0FFFFFFF};
}

inline int encode_regional(bool interp, bool fx, int nibble_qoi) {
    int raw = (interp<<30) | (fx ? 0x30000000 : 0) | (nibble_qoi & 0x0FFFFFFF);
    return ~raw;
}
```

### Step 2: 工厂改写

`GetQOI` 中 `qoi<0` 分支：
1. `decode_regional(conf.qoi)` 提取结构
2. `use_fx` → 从 `conf.qoiParams` 解析 TinyExpr → 构造 `RegionalFX`
3. `!use_fx` → `parse_qoi_nibbles(nibble_qoi)` → `assemble_group` → 包装为 `RegionalMean`/`RegionalMeanSq` 变体
4. `is_interp` → 选择 Interp 或 Block 版本的 QoI 类

### Step 3: test 更新

- QoiDef 的 `qoi` 值更新为新编码格式
- 新增 RegionalFX 测试用例
- 新旧编码等价性测试
- e2e 全覆盖

## 风险

- 旧编码 `~0`/`~1` 等价于 `~(0x00000000)`/`~(0x00000001)` — 兼容性天然保证
- 工厂逻辑从 4 个 switch case 变为 nibble 解析 + 分派，复杂度可控
