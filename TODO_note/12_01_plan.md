# 函数嵌套 & 基础函数参数化 — 总览 ✅ 已完成

## 两个 Feature

### Feature 1: 函数嵌套（0xE nibble）✅

新增 `0xE` nibble 作为 Compose 前缀运算符：`E f g → Compose(f, g) = f(g(x))`。

- `QoI_Compose.hpp` — Compose 类，支持 eval / check_comply / interpret_eb（数值链式导数）
- `QoIIf.hpp` — `parse_qoi_nibbles` 接受 `0xE`，`assemble_group` 检测后走 `parse_composition` 递归下降
- 恒等 elision：`Compose(f, XLin(1,0))` → `f`，`Compose(XLin(1,0), g)` → `g`
- e2e 测试通过 `0x14E`（Compose(Exp, X2)）

### Feature 2: base64 参数传入 ✅

- `Config::qoiParams` 存储 base64 编码的 `double[]`
- `qEBase`/`qELogB` 已删除
- `QoIIf.hpp` 内联 `base64_decode` + `ParamReader`
- 参数化基函数：XLin(A,B), XExp(base), LogX(base), XPower(expo)
- encoder + e2e roundtrip 测试全部通过
