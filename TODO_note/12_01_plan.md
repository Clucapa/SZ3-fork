# 函数嵌套 & 基础函数参数化 — 总览

## 两个 Feature

### Feature 1: 函数嵌套（0xE nibble）

已有 12 个 pointwise base function，用户需要组合约束如 `e^(x²)`、`√(|x|)`、`sin(x³)`。新增 `0xE` nibble 作为组合前缀运算符：

```
E f g → Compose(f, g) = f(g(x))
```

E 严格 2 操作数（不支持 `f(Σg)`）。解析器在 `parse_qoi_nibbles` 层面接受 `0xE` nibble，assembly 时检测到 `0xE` 走递归下降构建 `QoI_Compose` 树。

### Feature 2: base64 参数传入

通过 Config 新增 `std::string qoiParams` 写入 base64 编码的 double[]，与 `qoi` 并排平行传入。工厂在运行时 base64 decode → `ParamReader` 按 nibble 遍历顺序依次读取参数。

| nibble | 函数 | 参数数 | 默认 |
|--------|------|--------|------|
| 0x0 | XLin | 2 (A, B) | A=1, B=0 |
| 0x4 | XExp | 1 (base) | ℯ |
| 0x6 | LogX | 1 (base) | ℯ |
| 0xB | XPower | 1 (expo) | 2 |

## Config 改动

```cpp
// Config.hpp — 新增
std::string qoiParams;     // base64 encoded double[]; empty = no params

// Config.hpp — 删除
double qEBase = 1e-15;     // ✗
double qELogB = 2;         // ✗
```

INI 格式：
```
[QoISettings]
qoi = 1025
qoiParams = AAAAABAAAAAAAAAAF8AAAAAAACAACEA=
```

`save()`/`load()`：以 uint32 长度 + base64 字符串内容序列化。

## 编码示例

```
表达式: XLin(2, 1.5) + Exp(10) + XSquare
qoi = 0x401            // nibbles 低→高: [1, 0, 4] = XSquare, XLin, XExp
qoiParams(base64) = AAAAABAAAAAAAAAAF8AAAAAAACAACEA=
// decoded doubles: [2.0, 1.5, 10.0] → XLin 读 2, 1.5 → XExp 读 10 → XSquare 不读
```

```
表达式: Exp(3)(Square(x)) = e^(3x²)
qoi = 0x04E            // nibbles 低→高: [E, 4, 0] = Compose(Exp, XSquare)
qoiParams(base64) = AAAAAAAACUA=
// decoded doubles: [3.0] → XExp(base=3)
```

## 模块独立性

QoI 模块内部新增依赖：`<cstring>`（memcpy）、`<algorithm>`（base64 decode）。`std::string` 已在 Config 中广泛使用，整体新增依赖级别低。
